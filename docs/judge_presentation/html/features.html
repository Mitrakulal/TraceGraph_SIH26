What the AI actually sees.

It does not judge a transaction alone. It compares the transaction with its past timing, destination behaviour, synthetic IP pattern, and relationship context.

Result: High review priority. The model asks a human to inspect the synthetic pattern.

18 features become a reviewable score.

Transaction amount + fee
Timing + recent activity
Destination spread + fan-out
Synthetic IP rotation
Relationship degree + reach
